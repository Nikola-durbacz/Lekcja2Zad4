Różnice:
 spread – przyciski są równomiernie rozłożone na całej szerokości.
 spread_inside – pierwszy i ostatni przycisk są przy krawędziach, a wolne miejsce jest między nimi.
 packed – wszystkie przyciski są skupione obok siebie.
